# IMPOSTOR WORD GUESSER - Structured Prompt

## GAME OVERVIEW

- **Genre:** Social Deduction / Word Guessing
- **Theme:** Players know the secret word except the IMPOSTOR who must figure it out
- **Color Scheme:** PINK (UI elements, highlights, characters, effects)
- **Player Type:** GUEST PLAYER (No login required)
- **Game Mode:** STATIC ONLY (Single-screen gameplay with fixed elements)
- **Opponents:** ONLINE PLAYERS (Real players matched via server)
- **Difficulty Levels:** EASY, MEDIUM, HARD, EXTREMELY HARD

---

## CORE GAMEPLAY MECHANICS

### How It Works

- EVERYONE EXCEPT THE IMPOSTOR receives the SECRET WORD
- THE IMPOSTOR does NOT know the word
- Players take turns giving ONE-WORD CLUES about the secret word
- The Impostor must GUESS THE WORD based on the clues
- If Impostor guesses correctly → **IMPOSTOR WINS** 🎭
- If Impostor guesses wrong → **CREWMATES WIN** 🎉

## DETAILED GAME PHASES

### PHASE 1: LOBBY & WORD ASSIGNMENT

```
1. 4-10 players join (Guest players welcome!)
2. System randomly selects 1 IMPOSTOR
3. SECRET WORD is displayed to ALL players EXCEPT Impostor
4. Everyone sees: "You are CREWMATE" + the SECRET WORD
5. Impostor sees: "You are IMPOSTOR" + "[???] Figure out the word!"
6. 10-second countdown before game starts
```

### PHASE 2: CLUE GIVING (TURN-BASED)

```
1. Players take turns giving ONE-WORD CLUES
2. Clue order: Randomized each round
3. Clue Rules:
   ❌ Cannot use the actual word
   ❌ Cannot use part of the word (e.g., "apple" → "ap")
   ❌ Cannot use rhyming words (e.g., "cat" → "hat")
   ❌ Cannot use the word in a different language
   ✅ Can use synonyms (e.g., "happy" → "joyful")
   ✅ Can use related words (e.g., "beach" → "sand")
   ✅ Can use descriptions (e.g., "car" → "wheels")
   ✅ Can use actions (e.g., "swim" → "pool")
4. Impostor CAN give clues too (but they don't know the word!)
   - Impostor will fake clues based on previous clues
   - This adds to the deception!
```

### PHASE 3: IMPOSTOR GUESS

```
1. After all clues are given, IMPOSTOR makes 1 GUESS
2. If WRONG → Crewmates WIN! 🎉
3. If CORRECT → Impostor WINS! 🎭
4. If Impostor uses all hints (difficulty-based) → Auto-lose
5. Time limit based on difficulty
```

### PHASE 4: REVEAL & RESULTS

```
1. Show the SECRET WORD to everyone
2. Reveal who the IMPOSTOR was
3. Show all clues given
4. Points distributed
5. Rematch or new game
```

## SPECIAL MECHANICS

### 💡 HINT SYSTEM (Difficulty-based)

| Difficulty | Hints Available | Hint Type |
|------------|-----------------|-----------|
| Easy | 3 hints | Show first letter, category, number of letters |
| Medium | 2 hints | Show first letter, category |
| Hard | 1 hint | Show only the category |
| Extremely Hard | 0 hints | No hints at all! |

### 🚨 EMERGENCY MEETING

- **Triggered by:** Any player can call an emergency meeting (3 per game)
- **Purpose:** Discuss suspicious clues or accuse the Impostor
- **Accusation:** Players can vote to eliminate a suspected Impostor
- **If Wrong:** Eliminated player is revealed as Crewmate → Game continues
- **If Correct:** IMPOSTOR IS DEFEATED → Crewmates win!

### 📊 SUSPICION METER (Pink-themed)

```
Player_1: ████████░░░ 80% (Suspicious!)
Player_2: ███░░░░░░░░ 30% (Could be)
Player_3: ██████████ 100% (VERY SUSPICIOUS!)
Player_4: ██░░░░░░░░░ 20% (Probably innocent)
```

**Suspicion increases when:**

- Giving vague clues
- Copying other players' clues
- Taking too long to give a clue
- Giving clues that don't match the word
- Impostor gives suspiciously accurate guesses
